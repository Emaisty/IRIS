Iris in Arend

An Arend port of Rocq Iris, with step-indexed resource algebras, recursive iProp, ownership, invariants, masked weakest preconditions, thread-pool adequacy, and an Arend-native proof mode.

The full-arend-native-proof-mode branch was merged into main at e00f286 on 2026-09-30. It adds the parallel modular counter and its proofs, spawn/join, ghost libraries, numeric HeapLang binders, and Java metas that construct kernel-checked Arend proof terms. This is a working core and client port; coverage of the full upstream Rocq library remains partial.

Build

Run from the repository root. The build requires a JDK with Java 21 support, arend-lib installed under ~/.arend/libs (or AREND_LIBDIR), and an Arend CLI jar compatible with the extension API. arend.yaml declares language version 1.12. The build scripts default to the local patched checker at ~/Projects/Arend/cli/build/libs/cli-1.12.0-full.jar; that jar is not distributed in this repository. The scripts document the argument-first conversion fix as a requirement for the recursive Iris model.

export AREND_JAR=/absolute/path/to/cli-1.12.0-full.jar
export AREND_LIBDIR="$HOME/.arend/libs"
./scripts/build-proofmode-extension.sh
java -Xmx16g -jar "$AREND_JAR" -L "$AREND_LIBDIR" tests.proofmode
java -Xmx16g -jar "$AREND_JAR" -L "$AREND_LIBDIR" examples.parallel_counter_client

The extension is built into ext/; its registered virtual module is iris.proofmode.Meta. There is no src/iris/proofmode/Meta.ard to generate. Rebuild the extension after changing its Java sources.

For the dependency-ordered project check, which also builds the extension:

./scripts/typecheck-all.sh
AREND_RECOMPILE=1 AREND_SERIALIZE=1 ./scripts/typecheck-all.sh

The script fails on errors, unfilled goals, nonzero Java exits, or missing completion markers. It reports the number of modules actually attempted.

The 2026-09-30 toolchain audit rebuilt the latest official master and a variant with the String and guarded conversion changes. The patched source check passed 80 of 82 modules, including the current core, proof mode, and counter client. The two legacy factorial modules failed with 164 diagnostics; no goals were reported. The official full run timed out; individual source checks passed 63 modules and timed out on 19 at two minutes per module.
